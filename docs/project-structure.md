# 📂 Архитектура и структура проекта BetterYandexMusic

> **Версия:** 1.4.0  
> **Назначение:** Полный справочник по организации кодовой базы, модулям, компонентам и директориям проекта BetterYandexMusic.

---

## 🏗 Общая архитектура

Проект построен по модульному принципу и поддерживает работу на двух ключевых платформах:
1. **Браузерное расширение (Chromium: Chrome, Edge, Яндекс Браузер)** — внедряется через `content_scripts` (изолированный и основной контексты).
2. **Десктопное приложение (Electron: Windows, macOS, Linux)** — модифицирует `app.asar` официального клиента Яндекс Музыки через автоматический патчер (`patch.js`), внедряя код в preload и контекст страницы.

Для обеспечения синхронной работы всех платформ весь ключевой функционал вынесен в директорию `shared/`. Скрипт сборки `build.js` компилирует общий код в готовые дистрибутивы для расширения, Electron-клиента и инсталлятора.

## 🔍 Подробное описание ключевых подсистем

### 1. Подсистема «Моя волна» (`shared/vibe/`)
Модуль предоставляет три независимых режима отображения главной страницы:
- **Режим 1 (`default`):** Стандартный нативный вид Яндекс Музыки с 3D-колесом станции.
- **Режим 2 (`no_wheel`):** Компактный полноэкранный визуализатор. 3D-карусель скрыта, фоновый шейдер заезжает под левый полупрозрачный навбар. Кнопка «Настройка волны» позволяет открывать поповер с быстрыми чипсами по категориям («Настроение», «Жанры», «Артисты», «Характер»).
- **Режим 3 (`vibe_with_landing`):** Гибридный режим. В верхней части страницы сохраняется визуализатор Моей волны с черным навбаром, а при прокрутке вниз разворачивается полноценная лента персональных рекомендаций 1-в-1 с нативной страницей `landing/main`.
  - Модули секций (`vibe-section-*.js`) отрисовывают карточки с нативными классами и поведением.
  - Навигация по карточкам использует бесшовный SPA-роутер через React `AppRouterContext`.

> [!NOTE]
> Режим 3 активно развивается. Если при определенных условиях блок рекомендаций временно не отображается, достаточно перейти на нативную страницу «Для вас и тренды» (`/landing/main`).

### 2. Загрузчик треков и альбомов (`shared/track-downloader.js`)
- Позволяет скачивать одиночные композиции и целые альбомы/плейлисты.
- Поддерживает выбор качества: **FLAC Lossless** (максимальное несжатое качество) или **MP3 320 kbps** (высокое качество с оптимизацией дискового пространства).
- Скачивание альбомов автоматически архивируется в `.zip` с сохранением ID3-тегов и обложек.
- Интегрирован боковой виджет очередей скачивания (Edge Dock Drawer).
- В десктопной версии Electron доступен диалог выбора директории сохранения и опция автоматического открытия файла в Проводнике/Finder.

### 3. Аналитика прослушиваний (`shared/wrapped/`)
- Локальное хранилище на базе `IndexedDB`, собирающее данные обо всех проигранных треках, времени звучания, артистах и жанрах.
- Разделы: «Обзор», «Топ треков и артистов», «Жанры», «Календарь активности» (GitHub-style heatmap), «Stories» (пролистываемые карточки итогов).
- Возможность экспорта и импорта базы данных в формате JSON.

### 4. Синхронизация и совместное прослушивание
- Архитектура на основе WebSocket (`Socket.io`).
- Позволяет подключаться к комнатам по коду или прямой ссылке.
- Синхронизирует позицию трека, состояние паузы/воспроизведения и очередь композиций между браузерами и десктопными клиентами.

### 5. Сборка и распространение (`build.js`)
Команда `node build.js` (или `npm run build`):
- Объединяет стили из `shared/vibe/styles/*.css` в `shared/vibe/vibe-styles.js`.
- Собирает бандлы для десктопа: `yandex-sync-electron/desktop-sync.js` и копирует в `yandex-sync-installer/assets/`.
- Собирает браузерные скрипты: `isolated.js`, `main.js`, `soundcloud-bridge.js`.
- Компилирует серверный standalone-бандл с помощью `@vercel/ncc`.
